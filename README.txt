RUSSIAN TYPING TRAINER

This is a small installable web app for practicing Russian typing.

Files:
- index.html — the complete trainer and its 335-word vocabulary
- manifest.webmanifest — lets a phone install the site as an app
- sw.js — keeps the trainer available offline after the first visit

On iPhone:
1. Open the public website in Safari.
2. Tap the Share button.
3. Tap Add to Home Screen.
4. Tap Add.

Progress is stored only in the browser on the device where you practice.
